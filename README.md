# 📝 Speech Detection Notepad

A simple **speech-to-text notepad** built with the **Web Speech API**.  
It listens to your microphone in real-time, transcribes speech into text, and displays the results in a lined notepad-style interface.  
Offensive words are automatically filtered and replaced with emojis 💩.

---

## 🚀 Features
- 🎤 Live speech-to-text transcription
- 📒 Notepad-style UI (lined paper look)
- 💩 Automatic replacement of offensive words with emojis
- 🔄 Continuous listening (auto-restarts after pauses)
- 🖊 Editable text (you can correct results directly)

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (Web Speech API)**
